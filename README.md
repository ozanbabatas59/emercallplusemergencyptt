# emercallplusemergencyptt
 1. Giriş — EmercallPlus, afet ve acil durum senaryolarında kesintisiz iletişimi sağlamak amacıyla, internet
  bağlantısına ihtiyaç duymadan çalışabilecek şekilde geliştirilmiş Node.js tabanlı haberleşme sistemidir. Uygulama, web  sunucusu üzerinde çalışacak şekilde konumlandırılmış olup, yerel ağ (intranet) üzerinden erişilebilir. Bu sayede
  mobil şebeke veya internet altyapısının devre dışi kaldığı durumlarda dahi kullanıcılar sistemden kesintisiz
  faydalanabilir.
  2. HTTPS/SSL — Sistem mimarisi gereği güvenli iletişim sağlamak için HTTPS protokolü zorunlu tutulmuştur. Lokal
  ortamda sorunsuz çalışabilmesi adına SSL sertifikasının aktif hale getirilmesi gerekmektedir. Self-signed (kendinden
  imzalı) sertifikalar kullanılarak yerel kurulumlarda güvenli bağlantı sağlanabilir.
  3. Wi-Fi iletişim modülleri — EmercallPlus, Wi-Fi ağı üzerinden çalışan gelişmiş iletişim modüllerine sahiptir. Gerçek  zamanlı mesajlaşma, sesli haberleşme ve tek tuşla SOS sinyali gönderme gibi kritik özellikleri kullanabilir. Ayrıca
  konum bilgilerini paylaşmasına olanak tanıyarak, arama kurtarma ekiplerinin koordinasyon sağlamasına yardımcı olur.
  4. Düşük bant optimize — Düşük bant genişliğiyle çalışabilecek şekilde optimize edilen altyapı, minimum gecikme ile
  veri iletimini mümkün kılar.
  5. Sonu — EmercallPlus, sahada hızlı kurulum, kolay kullanım ve yüksek erişilebilirlik prensipleri doğrultusunda
  tasarlanmış olup, afet yönetimi ve kriz koordinasyonu için güvenilir bir çözüm sunar.

  eski metini. Sadece paragraflara bölün ve format edildim; kelimeleriyi üzün edildim.
